# AI_Nexus — Brainwave

AI_Nexus (codename: Brainwave) is a small React + TypeScript demo app that simulates an autonomous multi-agent research assistant (NEXUS AI). It includes a UI for running and visualizing simulated research sessions, multi-step agent traces, and generated, citation-backed reports.

## Stack
- Language(s): TypeScript + JavaScript (React)
- Framework / runtime: Vite + React (using the React plugin)
- Notable libraries:
  - @google/genai (Google AI integrations)
  - React 19, react-dom
  - Vite (build/dev tooling)
  - d3, recharts (charts / visualizations)
  - lucide-react (icons)
  - tailwindcss (styling utilities)
  - motion (animation helpers)
